# Jupyter Notebooks

This directory contains Jupyter notebooks for data exploration, analysis, and visualization.

## Available Notebooks

1. **data_exploration.ipynb** - Initial data exploration and understanding
2. **feature_engineering.ipynb** - Feature creation and engineering
3. **modeling.ipynb** - Machine learning model development
4. **dashboard.ipynb** - Interactive dashboard creation

## Usage

To run the notebooks:

```bash
jupyter notebook
```

Or to execute a specific notebook:

```bash
jupyter nbconvert --to notebook --execute data_exploration.ipynb
```
